# Task 11 - Example strategy on ticks

Spec: `doc/datamodel.md` sections 8, 9, 10.

## Scope
- New `examples/ticks/main.go`: a strategy implementing `Strategy`, `TradeStrategy` and `QuoteStrategy` that keeps the last valid NBBO per symbol (ignoring invalid quotes, counting them), logs each closed 5-second candle with its last mid, and submits one BUY when the first candle closes and one SELL on the next one.
- Wire it with `gotrader.GenericParquetTrades` (data folder, day and symbols from flags) and `BacktestBrocker` with default latency.
- README: add a section "Tick strategies" showing the optional interfaces and how the backtest fill works with latency.

## Out of scope
- Real data download, feature engine, LightGBM.

## Definition of Done
`go build ./...` succeeds and `go run ./examples/ticks` against a fixture day (generated by a small `-fixture` flag that writes two synthetic Parquet files using the Parquet test writers, exported for this purpose or duplicated in the example) completes, printing the fills and the final `ExecutionResult`.

## Semantic tests
1. Running the example on the synthetic fixture ends with an open position of 0 and exactly two fills logged (one buy, one sell), each with a price equal to a trade in the fixture.
2. The invalid quotes in the fixture are counted by the strategy and reported at shutdown, and none of them was used as the "last NBBO" for the fill logs.
